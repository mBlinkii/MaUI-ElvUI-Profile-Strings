# Chattynator in the MaUI Installer – design

## Intent
MaUI uses Chattynator as its chat addon (ElvUI's chat is already disabled in the MaUI private profile). When Chattynator is installed and enabled, the installer offers the MaUI Chattynator profile, just like Baganator.

## Goals
- New installer module `chattynator` that imports the MaUI profile as "MaUI" and activates it.
- Profile data generated by `convert.py` from Chattynator's SavedVariables (`CHATTYNATOR_CONFIG.Profiles.DEFAULT`).

## Non-goals
- No update/diff tracking beyond what other addon modules (Baganator, Details) do.
- No translation of locale-specific channel names.

## Approaches
1. **Import via `Chattynator.API.ImportString`** with a `CHATTY!1!` string encoded in game (same as Baganator). Chosen: uses the addon's own import path, which creates/switches the profile.
2. Writing `CHATTYNATOR_CONFIG` directly. Rejected: bypasses Chattynator's profile switching and needs a reload in all cases.
3. Storing an export string in `Profile/` only. Rejected by the user: data comes from the SavedVariables.

## Decisions
- Window anchored `BOTTOMLEFT` of UIParent (instead of the absolute TOPLEFT offset) at the user's size 574×252.
- Removed while converting: `chat_colors`, `debug`, temporary tabs. The migration flags (`combat_log_migration`, `applied_*`) stay, so Chattynator does not re-run its migrations on the imported profile.
- The BOTTOMLEFT offset is computed from the author's UIParent height (1440 at 2560x1440 and UI scale 0.5333): 40 px from the bottom.
- The "Dienste" channel exclusion stays as is (only takes effect on German clients).
- Supported only where `C_EncodingUtil` CBOR is available (same check as Baganator).

## Left to the builder
- Exact list of stripped keys after reading the SavedVariables, locale strings, page order.
