# MaUI Installer

The MaUI Installer sets up the complete MaUI v8.5 interface for you with a few clicks. You don't need to copy or import any profile strings.

## What it sets up

- **ElvUI**: choose **Tank/DPS** or **Heal**, each optionally with the **Cooldown Manager** layout
- **mMediaTag**
- **UI scale**
- **Blizzard Edit Mode** layout
- **Details!**
- **Baganator**
- **Chattynator**
- **MaUI M+ Timer**

You only see profiles for addons that you have installed and enabled. Anything you don't use is simply skipped.

## Installation

1. Install **ElvUI** and any of the optional addons listed above that you want to use.
2. Install the **MaUI Installer** from CurseForge (for example with the CurseForge app).
3. Log in to the game. The installer opens automatically the first time.

## Opening the installer

The installer opens on your first login. To open it again later, you can:

- type `/maui` in chat
- click MaUI in the addon compartment (the addon button next to the minimap)
- go to **ElvUI → MaUI** in the ElvUI settings

## Updates

When a new MaUI version comes out, you get a notice at login. The update only changes what's different in the new MaUI version, so your own adjustments elsewhere stay as they are.

Did you import MaUI by hand from the profile strings before (e.g. "MaUI v8.5 Heal CDM")? The installer recognizes these profiles and can update them too. Profiles older than v8 are shown but can't be updated. For those, run a fresh installation.

## Languages

The installer is available in English, German, Spanish, French, Italian, Korean, Portuguese (Brazil), Russian and Chinese (Simplified and Traditional).
