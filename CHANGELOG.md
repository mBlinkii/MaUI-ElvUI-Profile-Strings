# Changelog - MaUI Installer

## [ver. 1.0.2] - 20.11.2026
### 🔧 UPDATE
- UPDATE - [ElvUI]: All four layouts use the Forever portrait textures.
- UPDATE - [Baganator]: The bag window hides the guild, lock items, grouping and swap buttons.
- UPDATE - [Installer]: The addon page scrolls when the addon profiles do not fit, with a scroll bar in your class color.
### ✨ NEW
- NEW - [Chattynator]: The installer sets up Chattynator with the MaUI chat window, tabs and ElvUI skin when the addon is installed.

### 🔧 UPDATE
- UPDATE - [ElvUI]: All four layouts use the mMT Gold datatext in the right data panel.
- UPDATE - [ElvUI]: Updated profile settings, mover positions and accent colors.
- UPDATE - [Baganator]: Updated profile and categories for Retail.
### 📌 INFO
- INFO - Requires mMediaTag 4.20 or newer for the new gold datatext.
